ActorTerm is designed to be the terminal you reach for at every layer of your work — from a quick shell session to a long-running agent task. It is fast because it is built on Ghostty, focused because the panels stay out of your way, and safe because nothing opens without authorization.

Fast

Built on the Ghostty engine.

GPU-accelerated rendering keeps huge logs, busy prompts, and long-running builds fluid at any size. Startup is near-instant and memory stays flat, so the terminal never becomes the thing you are waiting on.

Focused

Notes and panels beside the prompt.

Per-session notes are auto-saved and restored across restarts, so context survives the machine. Git, file-tree, and editor panels sit in a tidy sidebar — review hunks, open files, and jump back to the prompt without losing your flow.

Safe

Authorized by token, never by default.

Agents and external tools open sessions through actorterm://new with a token you grant once. Notifications and dock badges announce arrivals without stealing focus, and every signed build is notarized for macOS 13 and later. 

$ open "actorterm://new?token=at_3f9k2..."

# ~/.config/actorterm.toml
[agent]
authorize = "on-launch"   # requested once
token      = "$ACTORTERM_TOKEN"
badge      = true            # announce arrivals
